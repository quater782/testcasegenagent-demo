# 测试用例推荐 Agent · Mock Demo

这是一个与生产后端完全隔离的纯前端演示，用于展示测试用例推荐 Agent 的完整用户旅程。

## 演示内容

1. Mock 缺陷与用例进入数据基座
2. AI 生成根因、修复动作、风险与统一标签
3. 按功能切片计算项目关系路由
4. 主 Agent 只负责沟通、追问与任务派发
5. 十个子 Agent 并行完成检索、风险分析、用例生成与结果编排
6. 支持文本输入和 10 行 Mock Excel 批量导入演示
7. 汇总带角色与证据的用例推荐
8. 用户反馈进入待审队列，经审批后沉淀为经验

## 数据与安全

- 页面中的项目、缺陷、用例、执行编号和统计值均为虚构数据。
- 演示不包含 API 请求、真实账号、后端地址或密钥。
- 交互状态只保存在当前浏览器的本地存储中，可随时通过“重置演示数据”清除。

直接打开 `index.html` 会进入推荐 Agent 首页并自动播放一次。顶部可单独重播文本或 Excel 演示；“新建会话”会刷新当前演示会话并从头自动重播。“批量上传”会模拟用户发送一个包含 10 行修改点的 Excel 文件，不会打开系统文件选择器或上传真实数据。
